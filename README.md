# HabitBloom — Habit Tracker (Starter Project)

Responsive habit tracker starter built with HTML, CSS and vanilla JavaScript. The interface is styled, but the JavaScript behavior is intentionally left as TODOs for practice.

## Run
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in your browser.
4. Complete the TODOs in `script.js`.
